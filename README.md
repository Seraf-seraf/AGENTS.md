# Backend Engineering

Плагин `backend-engineering` для инженерных задач: определить результат и границы, выбрать минимальное решение, проверить реальное поведение и завершить работу без лишнего расширения. Инструкции и итоговые ответы — на русском.

Общие правила находятся в [AGENTS.md](AGENTS.md): границы задачи, выбор решения, проверки, завершение работы и условия применения навыков. Специализированные навыки подключаются по характеру задачи.

## Навыки

| Навык | Когда применять |
| --- | --- |
| [`review-backend-architecture`](.agents/skills/review-backend-architecture/SKILL.md) | Проверка границ и зависимостей; замечания с доказательствами и минимальным исправлением. |
| [`verify-backend-change`](.agents/skills/verify-backend-change/SKILL.md) | Проверка изменения поведения, совместимости, реальных условий исполнения и значимых отказов. |
| [`ci-cd-ansible`](.agents/skills/ci-cd-ansible/SKILL.md) | Сборка, доставка, инфраструктура и восстановление; правила Ansible подключаются только для Ansible. |
| [`prepare-russian-commit`](.agents/skills/prepare-russian-commit/SKILL.md) | Сообщение или создание коммита по запросу: одна причина изменения, понятное описание на русском. |

`AGENTS.md` задаёт общий порядок работы и указывает, когда читать каждый навык. Подключать все навыки для каждой правки не требуется. Проектные инструкции определяют фактические инструменты, протоколы, архитектуру и команды проверки.

Проверки выбираются по изменённому контракту, его потребителям и обязательным gates проекта по [CI/CD-навыку](.agents/skills/ci-cd-ansible/SKILL.md). Сам факт изменения инфраструктурного файла не требует полного release-цикла. Навык задаёт подготовку стабильного кандидата, диагностику и основания повторов; результаты локальной проверки, реального CI и TEST deploy подтверждаются отдельно в пределах критерия завершения задачи. Имена сред и команды берутся из проекта; внешние действия выполняются в пределах разрешения пользователя. Для правок только документации или текста навыков проверяются содержимое, ссылки и формат поставки.

## Установка

Источник каталога плагинов: [Seraf-seraf/AGENTS.md](https://github.com/Seraf-seraf/AGENTS.md), ветка `main`.

1. Добавьте репозиторий как marketplace в поддерживающем его клиенте.
2. Установите плагин `backend-engineering`.
3. Подключите корневой [AGENTS.md](AGENTS.md) как общие или проектные инструкции в своей рабочей среде. Установка плагина сама по себе не подключает этот файл.

## Структура и упаковка

- `AGENTS.md` — общие инструкции; подключаются отдельно от плагина.
- `.agents/plugin.json` — манифест и версия плагина.
- `.agents/skills/` — навыки и связанные материалы.
- `.agents/plugins/marketplace.json` — каталог установки из репозитория; корень плагина — `.agents/`.

Для переносимого пакета поместите `plugin.json` и каталог `skills/` из `.agents/` в корень ZIP-архива. Каталог marketplace в этот архив не нужен.

Настройки моделей, разрешений и другие настройки клиента задаются в рабочей среде отдельно.

## Обновление

1. Обновите каталог и установленный плагин `backend-engineering` средствами своего клиента.
2. Отдельно сравните подключённый `AGENTS.md` с файлом из репозитория и перенесите изменения, сохранив собственные дополнения.

Изменения репозитория не обновляют установленные копии автоматически. Кеш плагина вручную не редактируется.
