# Совместимость

## Среды и требования

| Компонент | Версии и требования | Поддержка и ограничения |
| --- | --- | --- |
| Плагин ChatGPT | Пакет `software-engineering` 0.9.0 | Установка пакета и доступность файлов навыков подтверждены. `AGENTS.md` подключается отдельно. После обновления проверяйте версию, загруженную активной сессией. |
| Runner испытаний | Python 3.11+, Git; проверены Linux, Python 3.12.14 и Git 2.56.1 | Для завершения группы дочерних процессов по таймауту нужна POSIX-среда. Для Windows используйте WSL; нативное дерево процессов Windows не проверено. |
| Адаптер Codex CLI | Интерфейс `codex exec` 0.172.0-alpha.2 | Параметры сверены с `--help`. Для запуска нужны рабочий app-server и авторизация. Сквозной модельный прогон через этот адаптер не подтверждён. |
| Claude Code | Нативный адаптер не поставляется | Установка данного пакета и выполнение испытаний не проверены. Другой CLI можно подключить через command adapter. |
| Другие версии CLI, Codex IDE и macOS | Отдельно не проверены | Результаты проверки Linux не подтверждают эти сочетания клиента и ОС. |

Команды запуска, параметры адаптеров и статусы результатов описаны в [руководстве испытаний](../evals/README.md). Успешные тесты runner подтверждают его работу; результаты модели оцениваются отдельно для конкретных инструкций, клиента и среды.

## Подключение AGENTS.md и навыков

Корневой `AGENTS.md` можно подключить как общие или проектные инструкции отдельно от плагина; навыки не требуют его наличия. Он находит навыки по имени в доступном каталоге. Если навык отсутствует или в старой версии нет нужного справочника, общие нормы доступны по прямым резервным ссылкам из `AGENTS.md`.

Для работы без сети должны быть доступны локально три общих справочника:

- `analyze-change/references/technical-judgment.md`;
- `verify-change/references/engineering-rules.md`;
- `verify-change/references/verification-workflow.md`.

Актуальный плагин или локальная копия репозитория содержат эти файлы. Для специализированных задач также нужны справочники соответствующего навыка.

В Codex инструкции собираются из глобального и проектного уровней. Более близкие к рабочему каталогу файлы уточняют общие; на каждом уровне `AGENTS.override.md` имеет приоритет перед `AGENTS.md`. Лимит объединённого текста задаётся `project_doc_max_bytes`, по умолчанию — 32 KiB. [Документация Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

ChatGPT и Codex сначала загружают имя и описание навыка, при его выборе — полный `SKILL.md`. Тематические справочники читаются по указанным в навыке условиям. [Документация навыков](https://learn.chatgpt.com/docs/build-skills).

## AGENTS.md в Claude Code

Claude Code читает `AGENTS.md` напрямую с версии `2.1.277`, если в рабочем каталоге и выше нет `CLAUDE.md` или `CLAUDE.local.md`, меняющих выбор инструкций. В остальных случаях можно использовать импорт `@AGENTS.md` из `CLAUDE.md`. Поддержка файла инструкций не подтверждает совместимость манифеста плагина. [Документация Claude Code](https://code.claude.com/docs/en/memory#agentsmd).
