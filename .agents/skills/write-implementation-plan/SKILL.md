# Составление плана

Учитывать действующие общие и проектные инструкции при их наличии. Навык не требует отдельного файла общих инструкций. Результат — однозначный MD-план с принятыми проектными решениями; исполнитель не должен заново проектировать задачу. Подготовка плана не запускает реализацию, добавление в индекс Git или коммиты описанной задачи.

## Читать материалы по части работы

Сначала определить, какая часть плана поручена. До подготовки, изменения или проверки этой части прочитать материалы соответствующих строк и выполнить все применимые требования. Таблица не заменяет подробную схему и не разрешает пропускать её обязательные поля. Для обновления одного раздела читать связанные материалы, а не автоматически весь каталог; готовые выводы и уже прочитанные правила переиспользовать.

| Часть работы | Обязательный материал |
| --- | --- |
| Подготовка содержания плана, выбор относящихся профильных критериев, разрешение существенных неизвестных или итоговая проверка плана. | [Подготовка и проверка](references/planning-workflow.md). Профильные правила подключаются только к относящимся частям задачи. |
| Составление или изменение структуры документа, этапов, зависимостей, разрешённых путей, команд проверок или состава индекса Git. | [Структура плана и этапа](references/plan-structure.md): разделы, все поля этапа и общая приёмка. |
| План передаётся исполнителю либо меняются назначенный объём, продолжение, параллельная работа, индексация, коммиты или условия остановки. | [Ограниченное исполнение](references/execution-rules.md): поместить относящиеся правила в сам план, чтобы исполнителю не требовался этот навык. |
| Меняется или испытывается сам навык. | [Калибровочные сценарии](references/calibration-scenarios.md); они не запускаются при составлении каждого плана. |

Для технической оценки решений применять [независимость оценки](../analyze-change/references/technical-judgment.md); для существенного неразрешённого вопроса использовать [оценку](../analyze-change/references/assessment.md) или [архитектурные критерии](../analyze-change/references/architecture.md). Выбор проверок принадлежит [проверке изменений](../verify-change/SKILL.md), относящаяся инфраструктура — [CI/CD](../ci-cd/SKILL.md), порученные коммиты — [подготовке коммита](../prepare-commit/SKILL.md). Ссылки не предписывают выполнять все эти работы.
