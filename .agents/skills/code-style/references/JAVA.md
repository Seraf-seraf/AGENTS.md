# Java

Применимость: `.java`.

## Источники

- Java: https://google.github.io/styleguide/javaguide.html

## Приоритеты и локальные дополнения

Правила конкретного проекта, включая formatter/linter-конфигурацию, имеют приоритет над локальными дополнениями этого файла; дополнения — над указанным внешним стандартом.

Явно указывать типы параметров и возвращаемые типы методов; не добавлять избыточные аннотации локальным значениям, когда тип очевиден и язык допускает вывод.

## Правила по темам

### Форматирование
- Два пробела на уровень блока; одна инструкция на строку (Block indentation, One statement per line).

### Именование
- Классы — `UpperCamelCase`, методы — `lowerCamelCase` (Naming).

### Импорты и модули
- Не использовать wildcard imports (No wildcard imports).

### Типы и конструкции
- Объявлять по одной переменной в декларации, вблизи использования (Variable declarations).

## Исключения/конфликты

Краткие правила не заменяют полный источник. При спорном решении читать относящийся раздел указанного стандарта. Неприменимые темы не добавлять искусственно. Конфликт разрешать по приоритетам выше; недоступность источника обозначать как ограничение проверки, без автоматической замены стандарта.
