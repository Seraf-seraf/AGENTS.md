# Go

Применимость: `.go`.

## Источники

- Go: https://google.github.io/styleguide/go/

## Приоритеты и локальные дополнения

Правила конкретного проекта, включая formatter/linter-конфигурацию, имеют приоритет над локальными дополнениями этого файла; дополнения — над указанным внешним стандартом.

Типы параметров и результатов функций задаются сигнатурой Go; не добавлять избыточный тип локального значения, когда он очевиден из инициализации.

## Правила по темам

### Форматирование
- Использовать формат `gofmt` (Guide → Formatting). Не заменять его ручным правилом пробельных отступов.

### Именование
- Многословные имена — `MixedCaps`/`mixedCaps`, без подчёркиваний; регистр начала зависит от экспортируемости (Guide → MixedCaps). Учитывать перечисленные там исключения, например сгенерированный код.

### Типы и конструкции
- Не переносить синтаксис аннотаций другого языка на Go; следовать сигнатурам языка.

## Исключения/конфликты

Краткие правила не заменяют полный источник. При спорном решении читать относящийся раздел указанного стандарта (для Go — документы Guide/Decisions из указанного индекса). Неприменимые темы не добавлять искусственно. Конфликт разрешать по приоритетам выше; недоступность источника обозначать как ограничение проверки, без автоматической замены стандарта.
