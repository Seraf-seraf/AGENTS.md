# JavaScript и TypeScript

Применимость: JavaScript: `.js`, `.mjs`, `.cjs`, `.jsx`; TypeScript: `.ts`, `.mts`, `.cts`, `.tsx`. Правила JSX/TSX определяются также конфигурацией проекта.

## Источники

- JavaScript: https://google.github.io/styleguide/jsguide.html
- TypeScript: https://google.github.io/styleguide/tsguide.html

## Приоритеты и локальные дополнения

Правила конкретного проекта, включая formatter/linter-конфигурацию, имеют приоритет над локальными дополнениями этого файла; дополнения — над указанным внешним стандартом.

В TypeScript явно указывать типы параметров и возвращаемые типы функций и методов. Не добавлять избыточные аннотации локальных значений с очевидным выводимым типом. Это перенесённое правило проекта: Google TypeScript Guide допускает вывод типов и оставляет аннотации возвращаемого типа на усмотрение автора.

## Правила по темам

### Форматирование
- JavaScript: два пробела на уровень блока, точки с запятой, одинарные кавычки для обычных строк (разделы Formatting и String literals).

### Именование
- Классы — `UpperCamelCase`, методы и обычные переменные — `lowerCamelCase` (Naming).

### Импорты и модули
- В TypeScript использовать ES-модули `import`/`export`, а не `namespace` для организации кода (Use modules not namespaces).

### Типы и конструкции
- В TypeScript использовать `const` для непереназначаемых значений, `let` при переназначении (Local variable declarations). Локальное требование аннотаций указано выше.

## Исключения/конфликты

Краткие правила не заменяют полный источник. При спорном решении читать относящийся раздел указанного стандарта. Неприменимые темы не добавлять искусственно. Конфликт разрешать по приоритетам выше; недоступность источника обозначать как ограничение проверки, без автоматической замены стандарта.
