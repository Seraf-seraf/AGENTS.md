# Shell

Применимость: `.sh`, `.bash` и скрипты Shell. Определять фактический интерпретатор по shebang, способу запуска и правилам проекта, а не только по расширению. Различать Bash, POSIX `sh` и другие оболочки; не переносить синтаксис и расширения между ними автоматически.

## Источники

- Bash: https://google.github.io/styleguide/shellguide.html — для POSIX `sh` использовать только совместимые правила этого источника; не считать Bash-расширения переносимыми.

## Приоритеты и локальные дополнения

Правила конкретного проекта, включая formatter/linter-конфигурацию, имеют приоритет над локальными дополнениями этого файла; дополнения — над указанным внешним стандартом.

Новых локальных дополнений нет.

## Правила по темам

### Форматирование
- Два пробела; без табуляции, кроме тела `<<-` here-document. В существующем файле сохранять его отступы (Indentation).

### Именование
- Функции — строчные слова с подчёркиваниями (Function Names).

### Типы и конструкции
- Заключать подстановки переменных в двойные кавычки, кроме явно описанных в Quoting исключений.
- В Bash переменные внутри функций объявлять `local`, если значение не должно выходить наружу (Use Local Variables).
- В POSIX `sh` не использовать `local`, массивы Bash, `[[ ... ]]` и другие непереносимые расширения. Для изоляции временных переменных при необходимости использовать параметры функции или подстановку/тело в подоболочке, учитывая изменение семантики побочных эффектов. Для другого диалекта применять только конструкции, поддерживаемые заявленным интерпретатором.

## Исключения/конфликты

Краткие правила не заменяют полный источник. При спорном решении читать относящийся раздел указанного стандарта. Неприменимые темы не добавлять искусственно. При проверке синтаксиса или исполнения использовать фактический целевой интерпретатор; успешный запуск в Bash не подтверждает переносимость POSIX-скрипта. Конфликт разрешать по приоритетам выше; недоступность источника обозначать как ограничение проверки, без автоматической замены стандарта.

## Короткие примеры

```bash
greet() {
  local name="$1"
  printf 'Hello, %s\n' "${name}"
}
```

POSIX `sh`:

```sh
greet() {
  printf 'Hello, %s\n' "$1"
}
```
