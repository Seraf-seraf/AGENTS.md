# Shell

Применимость: `.sh`, `.bash` и скрипты Bash. Для POSIX sh и других оболочек сначала учитывать фактический интерпретатор; Bash-конструкции не переносить автоматически.

## Источники

- Shell: https://google.github.io/styleguide/shellguide.html

## Приоритеты и локальные дополнения

Правила конкретного проекта, включая formatter/linter-конфигурацию, имеют приоритет над локальными дополнениями этого файла; дополнения — над указанным внешним стандартом.

Новых локальных дополнений нет.

## Правила по темам

### Форматирование
- Два пробела; без табуляции, кроме тела `<<-` here-document. В существующем файле сохранять его отступы (Indentation).

### Именование
- Функции — строчные слова с подчёркиваниями (Function Names).

### Типы и конструкции
- Заключать подстановки переменных в двойные кавычки, кроме явно описанных в Quoting исключений.
- Переменные внутри функций объявлять `local`, если значение не должно выходить наружу (Use Local Variables).

## Исключения/конфликты

Краткие правила не заменяют полный источник. При спорном решении читать относящийся раздел указанного стандарта. Неприменимые темы не добавлять искусственно. Конфликт разрешать по приоритетам выше; недоступность источника обозначать как ограничение проверки, без автоматической замены стандарта.

## Короткие примеры

```bash
greet() {
  local name="$1"
  printf 'Hello, %s\n' "${name}"
}
```
