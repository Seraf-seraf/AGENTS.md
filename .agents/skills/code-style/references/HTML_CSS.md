# HTML и CSS

Применимость: HTML: `.html`, `.htm`; CSS: `.css`; соответствующие фрагменты шаблонов. JSX/TSX не является HTML.

## Источники

- HTML/CSS: https://google.github.io/styleguide/htmlcssguide.html

## Приоритеты и локальные дополнения

Правила конкретного проекта, включая formatter/linter-конфигурацию, имеют приоритет над локальными дополнениями этого файла; дополнения — над указанным внешним стандартом.

Новых локальных дополнений нет.

## Правила по темам

### Форматирование
- Два пробела на уровень, без смешивания пробелов и табуляции; убирать конечные пробелы (General Formatting Rules).

### Именование
- Имена элементов и атрибутов HTML, CSS-свойства писать строчными (Capitalization). Не менять регистр значений, чувствительных к нему, вопреки контракту проекта.
- Классам CSS давать осмысленные имена по назначению, а не по внешнему виду (Class Naming).

## Исключения/конфликты

Краткие правила не заменяют полный источник. При спорном решении читать относящийся раздел указанного стандарта. Неприменимые темы не добавлять искусственно. Конфликт разрешать по приоритетам выше; недоступность источника обозначать как ограничение проверки, без автоматической замены стандарта.

## Короткие примеры

```html
<article class="news">
  <h2>Новости</h2>
</article>
```

```css
.news {
  color: #333;
}
```
