# Окно доступности

Модуль `availability.py` определяет, открыто ли временное окно события.

Публичный интерфейс: `is_open(starts_at, ends_at, now, cancelled=False)`.
Все значения времени — целые секунды одной шкалы; вызывающий код гарантирует
`starts_at < ends_at`. Функция возвращает `bool` и не читает системные часы.

## Действующий контракт

- Начало окна включительно: в `starts_at` событие уже доступно.
- Конец окна исключительно: начиная с `ends_at` событие недоступно.
- До начала и после конца событие недоступно.
- При `cancelled=True` событие недоступно в любой момент.

Изменение требований и публичного интерфейса в текущую задачу не входит.
