# API каталога артефактов

`api.list_artifacts_response(records)` представляет публичную границу
`GET /v1/artifacts`: возвращает пару `(status_code, body)`, где `body` —
сериализованный JSON. Действующий формат ответа задан в `openapi.json`.

Аргумент `records` содержит корректные записи хранилища с полями `id`,
`title`, `media_type`, `revision` и `byte_length`. Модуль `artifacts`
строит из них прикладное представление, а модуль `api` формирует ответ.
Значения берутся из переданных записей. Их порядок сохраняется; исходные
список и словари не изменяются. Пустой список — корректный успешный ответ.

Область работы — соответствие реализации этому контракту. Публичная
граница и действующий контракт сохраняются. Внутреннее устройство можно
менять в необходимых пределах. Внешние зависимости и сетевой сервер
для проверки не требуются.

Штатные проверки: `python3 -m unittest -v`.
